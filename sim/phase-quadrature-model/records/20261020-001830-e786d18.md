## 1. Topology, edge definitions and reset semantics

- Two D flip-flops. FF_I: rising-edge triggered on the 2x clock C2X, D = NOT Q_Q, output = CLK. FF_Q: falling-edge triggered on C2X, D = Q_I, output = CLK90. Feedback counter input taken from CLK (after the /2).
- State order on alternating R,F edges from (I,Q)=(0,0): (1,0) -> (1,1) -> (0,1) -> (0,0). All four states lie on this one cycle; the Johnson cross-coupling fixes the Q-lags-I ordering for every power-up state.
- RESETB: active low, asynchronous; forces I=Q=0 while low. Release: the first C2X edge at or after release is captured (a parameter selects whether an edge exactly at release counts). Recovery-window instants are flagged, not resolved.
- Phase of an output edge pair = 360 * (CLK90 edge - preceding CLK edge) / output period, in degrees of the output period; positive = CLK90 lags CLK; reported for rising-to-rising and falling-to-falling separately. Period = mean CLK rising-to-rising time. Duty = mean high time / period.
- Skipped transient: first 2 CLK rising edges (steady cases); post-restoration cases measure from 4 T2 after restart.

## 2. Analytical predictions (closed form; not produced by the model)

- Output period = 2*T2. CLK90 lags CLK by D*T2 + delta, i.e. phase = 180*D + 180*delta/T2 degrees. D=50 %, delta=0 -> 90 deg; D=45 % -> 81 deg; D=55 % -> 99 deg.
- Output duty of each output = (T2 + tcq_fall - tcq_rise)/(2*T2) = 50 % for equal rise/fall clock-to-out, **independent of input duty**. The /2 therefore restores output duty while transferring the input duty error into the CLK-CLK90 phase.
- Setup margins: FF_Q samples CLK at the falling edge: D*T2 - tcq_I - tsu; FF_I samples NOT CLK90 at the next rising edge: (1-D)*T2 - tcq_Q - tsu. tsu/tcq of this design are UNKNOWN.

## 4. Defeating control

Group G substitutes an assumed perfect-quarter-cycle generator (always 90.000 deg) for the model at D_in=45 % and checks it against the closed form. The check must fail it; a harness that cannot do so would not detect an assumed-quadrature design. All three frequencies detect it (see rows in group G).

## 5. Timing-error budget (parameterized; no consumer tolerance is recorded)

DR-009 records the consumer's operating points (25 and 50 MHz output, 100 MHz stretch) and that the consumer today derives a quarter-cycle clock with a delay element. **It records no setup/hold time, data window, permitted CLK-to-CLK90 phase window, or jitter allowance at the consumer.** The missing requirement is therefore exactly: (a) the allowed CLK90-CLK phase window (degrees or ps) at each of 25/50/100 MHz, (b) the consumer flop setup/hold times that window protects, and (c) the allowance for CLK and CLK90 jitter. Nothing below is an approved tolerance.

- Metastability, setup/hold physics, and recovery behaviour: flagged instants are resolved deterministically (old value) and reported as unresolved.

- The loop: Kvco, loop gain and lock dynamics are not simulated, so this record neither supports nor refutes the proposal's loop-gain argument (see the correction in the proposal).
