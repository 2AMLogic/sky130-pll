# Pinned klayout-tools (`klt`) install for layout/'s DRC/LVS flow (issue #2).
#
# 2AMLogic/sky130-bandgap's own layout/requirements.txt (source commit
# f3b2b2e461938e323670498bcdbe9f4ec7de699b) pins an exact git commit rather
# than a PyPI version, because at the time it was written PyPI's
# `klayout-tools` release (v0.1.0) shipped only five verbs
# (`layers`/`stats`/`cells`/`drc`/`pdk`) -- this flow needs `gen`, `extract`
# and `lvs` too, which were `main`-only.
#
# That gap has since closed: PyPI now has `klayout-tools==0.2.0`
# (https://pypi.org/project/klayout-tools/0.2.0/), and it ships `gen`/
# `extract`/`lvs` -- verified directly in this sandbox (`klt gen mos_array`,
# `klt drc`, `klt extract`, `klt lvs` all present and exercised by
# layout/bin/run-trivial-cell-flow.sh, see layout/README.md). So this pin is
# a plain PyPI version, not a git commit -- simpler, and still reproducible
# (a version pin, re-fetched, is byte-identical; bump it deliberately and
# re-run layout/bin/run-trivial-cell-flow.sh to refresh the checked-in
# record when picking up new `klt` capability).
klayout-tools==0.2.0
